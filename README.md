# 📚 BookVerse — Modern Online Bookstore Platform

An enterprise-grade Full-Stack Online Bookstore built with **React (Vite)**, **Node.js/Express**, **MongoDB**, and **MWallet Gateway Integration**.

---

## ✨ Features

- **Storefront & Catalog**:
  - Full-text search and category filtering
  - Best sellers, featured books, and new arrivals
  - Book rating & verified customer review system
  - Shopping cart & wishlist management
- **MWallet Payment Integration**:
  - Secure mobile wallet checkout workflow
  - Real-time stock reservation and automated inventory replenishment alerts
  - Instant digital invoice generation
- **Admin Management Dashboard**:
  - Comprehensive store performance analytics & gross revenue metrics
  - Real-time inventory alerts (Low stock & Out of stock)
  - Book catalog management (CRUD operations)
  - Order progression management (Processing, Shipped, Delivered)
  - Payment audit trail

---

## 🚀 Tech Stack

- **Frontend**: React 18, Vite, Redux Toolkit, Tailwind CSS, Lucide React, Axios
- **Backend**: Node.js, Express.js, MongoDB / Mongoose, JWT Authentication, bcryptjs
- **Payment Engine**: MWallet API Gateway (Purchase & Verification)

---

## 🛠️ Getting Started

### 1. Prerequisites
- Node.js (v18+)
- MongoDB (Local or MongoDB Atlas)

### 2. Backend Setup
```bash
cd backend
npm install
# Configure your .env file based on .env.example
npm run dev
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
